# Application portfolios

Tailored portfolio packets prepared for specific opportunities. Use the packet shared with you; these editions are not interchangeable applications.

[Open the public experience](https://jonathankhobson.github.io/portfolio/).

## Maintenance

This repository distributes reviewed application-specific pages and downloads. Authoring evidence and application records remain private. The complete per-packet generator is not contained here. Identify the packet owner and its reviewed inputs before regenerating anything; do not infer permission to reuse employer-specific copy in another application.

See [AGENTS.md](AGENTS.md) for change and verification boundaries. Report reproducible problems through this repository’s Issues, including the affected public URL. Do not include private records or credentials.
